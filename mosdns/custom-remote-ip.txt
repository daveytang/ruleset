# 强制改走国外 DNS 的 IP 段
#
# 只在处理「不在任何域名表里的未知域名」时生效：国内 DNS 返回的 IP 若落在
# 本表内，就丢弃该结果并改问国外 DNS。用来对付被投毒或被劫持到特定 IP 的情况。
#
# 什么时候加到这里：
#   - 发现国内 DNS 把某些未知域名统一解析到某个错误 IP（劫持页、投毒地址）
#
# 格式：一行一个 IP 或 CIDR。
#   ✓ 198.51.100.5
#   ✓ 198.51.100.0/24
#   ✗ 198.51.100.5 劫持地址   （行尾不能写备注，同步会被拒绝并指出行号）
#
# 本表判定在 custom-cn-ip.txt 之前，两边冲突时以本表为准。
